## 1. 审阅结论与关键链路

### 1.1 Workflow decider / commandService 接线

- `server/src/taskboard/workflow/decider.ts`
  - execution claim 统一校验 delivery/advisory/integration/remediation 的 purpose 与状态。
  - terminal、merged、blocked 任务禁止隐式再次派发；integration 仅允许 merge；review 仅允许合法待复核任务。
  - resolution 状态转移集中决策：advisory completed→done，remediation approved→done，delivery approved→ready_to_merge，integration completed→done。
- `server/src/taskboard/storeExecutionLifecycle.ts`
  - `claimExecution` 已调用 `assertExecutionRequestAllowed`，覆盖普通派发、直接执行、评论新建 execution 和自动流程 claim。
- `server/src/taskboard/v2Store.ts`
  - `resolveExecutionV2` 已调用 receipt fencing、workflow facts、contract outcome、decider 与 canonical resolution command。
- `server/src/taskboard/workflow/commandService.ts`
  - canonical Resolution 以 execution/resolutionId 双键幂等；冲突 payload 拒绝。
  - receipt 绑定 executionId/attemptId/purpose/workflowEpoch/fenceEpoch。
  - terminal/merge convergence 立即 fence 活跃 execution，写 cancellation outbox 与审计 change。
- `server/src/taskboard/executionService.ts`
  - reconcile 已消费 cancellation outbox，并将 runtime run 标记为 cancelled。

### 1.2 Schema 注册与持久化

- `server/src/taskboard/store.ts` 已注册：
  - `${prefix}_taskboard_resolutions`
  - `${prefix}_taskboard_remediation_attempts`
  - `${prefix}_taskboard_cancel_outbox`
- `server/src/taskboard/v2Schema.ts` 已创建上述表、索引及 workflow/execution fencing 字段，并保护 active PR source 唯一性。
- execution 查询与 context 查询已关联 canonical resolution，返回 outcome/summary/toStatus/ignoredReason/fence 信息。
- 为通过 max-lines 棘轮且不扩大既有大文件，抽取：
  - `storeTaskAccess.ts`
  - `integrationSourceMapper.ts`
  - `workflow/cancellationOutbox.ts`
  - `workflow/resumeService.ts`

### 1.3 Advisory / merge / remediation / continuation / resume 闭环

- Advisory：共享类型、路由 schema、Agent tool schema、创建弹窗、详情展示、workflow contract、repo capability 限制和完成态均已接通。
- Merge：provider 已合并回执、正常 merge、unknown reconcile 均进入统一 finalize；delivery/source/integration/remediation 聚合收敛，并 fence 非当前活跃 execution。
- Remediation：attempt 历史落表；approved 后 source 恢复 pending 且任务收敛 done；merge 先到时剩余 remediation 收敛 canceled/superseded。
- Continuation：terminal/merged/blocked 不再续跑；无 active integration execution 时评论只能创建 merge execution；active formal execution 只 steer、不改写任务状态。
- Resume：`POST /api/taskboard/tasks/:id/resume` → service → transactional resume 完整接通；integration 必须显式选择 `needs_human` sourceIds；新增 server route 与 Web API 测试。
