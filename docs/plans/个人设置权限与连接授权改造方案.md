# 个人设置「我的权限」与连接授权改造方案

> 日期：2026-09-09  
> 范围：Web 个人设置、能力中心连接器、权限展示名称  
> 状态：已完成代码实施，待 PR 检查与真实账号业务验收

## 1. 已确认的产品决策

1. 菜单名称「我的权限」保持不变。
2. 个人设置仍使用「个人 / 偏好 / 访问 / 数据」四个分组；剩余菜单不改名、不换组、不重排。
3. 删除个人设置中的「连接与授权」。
4. Google 长期账号授权迁到「能力中心 → 连接器 → Google Workspace」。
5. 运行时工具批准迁到「对话与模型 → 操作前确认」。
6. 个人调试模式迁到「对话与模型 → 显示详细执行过程」。
7. 「我的权限」只展示当前已生效、可使用的权限，不展示不可用项、原因码、技术 ID 或治理诊断。
8. 「外观与布局」保持不变，只负责视觉设置。

## 3. 页面职责

### 我的权限

- 数据仍以服务端权威权限判定为准，不在前端另建权限算法。
- 只渲染判定结果为 `available` 的 Agent、技能、连接器和执行环境。
- Agent 和技能使用发布定义中的业务名称；缺少名称时使用通用业务称呼，不回退到资源 ID。
- 不渲染不可用数量、失败原因、决定因素、策略版本、访问链或任何内部标识。
- 空态：`当前没有可展示的有效权限。`
- 异常态：`暂时无法加载我的权限。`，并提供重新加载。
- 管理员诊断数据和组件继续保留，但不与普通用户页面建立入口。

### 对话与模型

- 默认模型只保存默认模型字段，不顺带覆盖操作确认偏好。
- 「操作前确认」提供三档业务表达：每次操作前询问、自动执行低风险操作、尽量自动执行。
- 「显示详细执行过程」沿用现有调试模式门禁；组织未开放时只提示“当前组织未开放此功能”。
- 对话通知保留原位置。

### 能力中心连接器

- Google Workspace 卡片和详情承接连接、重新连接、扩展权限、暂停、恢复和断开。
- 打开 Google 授权页之前，先展示服务端返回的用途、授权范围、数据去向和撤销方式，并要求用户明确确认。
- 撤销活动 OAuth Grant 前，先取得签名预览；预览过期或有阻断项时拒绝提交。
- 断开旧连接但没有活动 Grant 时，沿用受控的兼容断开流程。
- Token、Secret 不进入页面 DTO、提示或日志。

## 5. 实施工作包与回滚点

### WP1：精简「我的权限」

- 增加普通用户专用权限列表，仅显示可用资源和业务名称。
- 从页面移除调试开关和权限诊断。
- 服务端补齐 Agent、技能的业务展示名称。
- 回滚点：独立回滚 WP1 commit，不影响真实权限数据。

### WP2：归并对话行为设置

- 将操作确认和详细执行过程迁到「对话与模型」。
- 拆分设置保存字段，避免不可见字段被连带覆盖。
- 回滚点：独立回滚 WP2 commit，无数据迁移。

### WP3：Google 授权迁入连接器中心

- 在 Google Workspace 详情中增加授权预览、扩权和安全撤销。
- 合并 connection 状态与治理 Grant 状态，不降低现有确认强度。
- 回滚点：独立回滚 WP3 commit。

### WP4：删除重复页面和路由

- 删除个人设置注册项和旧组件。
- 历史路径跳转到连接器中心。
- 清理类型、图标和测试残留。
- 回滚点：独立回滚 WP4 commit；WP2、WP3 新入口可继续工作。

### WP5：整体验证

- 运行 Web、Shared、Server 类型检查和测试，以及 Web 构建。
- 检查桌面和移动断点下菜单、文案、旧链接与关键交互。
- 静态检查、浏览器验收、真实账号验收分别记录，不互相替代。

## 6. 验收清单

### 自动化验收

- 「我的权限」只渲染可用资源，不包含内部 ID、英文原因码或诊断信息。
- 权限接口失败不会被误报为“没有权限”。
- 操作确认三档与既有偏好字段映射一致。
- 修改默认模型不会覆盖操作确认偏好。
- 调试功能未开放时开关禁用并只显示业务文案。
- Google 授权确认发生在打开第三方授权页之前。
- OAuth 撤销使用当前签名预览；过期或有阻断项时不能提交。
- 个人设置注册表和页面不再包含「连接与授权」。
- 三个历史连接路径均跳到连接器中心。

### 业务验收

- 桌面端和移动端的个人设置目录结构正确。
- 真实账号的「我的权限」只展示实际可用权限和业务名称。
- Google 测试账号能在连接器详情读取连接状态；真实授权或撤销仅使用专用测试账号。
- 「外观与布局」行为无变化。
