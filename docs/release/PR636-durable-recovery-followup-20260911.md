## F06：固定本次交接的旧实例

旧实例身份在交接时捕获一次，包括角色、颜色槽、PID、主机 boot ID、进程启动 ticks、systemd InvocationID，以及 release/Manifest/run/attempt 和目标摘要。后续观察不再读取当前活动色反推旧实例；发信号前再次核验该固定身份，不对已经复用的槽位或 PID 发信号。

退役观察材料和只读观察器保存在主机 `/var/lib/agent-saas-release-recovery/retirements/<run>-<attempt>/`，使用独立 systemd 单元在 runner 结束后继续执行并支持主机重启后重新观察。它不停止旧实例、不清理旧槽位、不执行数据库写入。观察期限绑定原始开始时间，重启不会无限延长期限；超时或证据失败输出明确的 `needs_human` 告警和受保护的本地材料。

Runtime 从进入排空开始保留在途 run、租户和旧 owner 的清单，包含排空期间新注册的 run；注销不会抹掉待核验记录。清单超过上限、身份冲突或缺失不能成为完整证明。只有排空与清理成功、计数归零、固定进程确已退出，并且只读 PostgreSQL 查询证明任务已有持久化终态、无旧调用悬挂的合法暂停状态，或存在持有效 lease 的新 owner，才报告旧工作完成。未知工具结果、未送达的取消、过期 owner、其他租户、清理错误或缩减的清单均不能冒充完成。

PostgreSQL 查询使用只读、可重复读事务和连接、语句、锁等待预算。报告仅包含计数和发布/进程身份，原始 run/租户清单留在主机 0600 私有文件中，不进入公共诊断 artifact。

### 首次升级与兼容边界

已经在线的旧二进制不会因为部署脚本升级而自动产生新格式的退役清单。旧协议仍可证明进入排空，但不能被标为完整结清；缺少证据时保持 `draining_or_unverified` 并要求人工核对。旧进程异常退出或重启丢失未留存的 marker 也不会被虚构为安全完成。新协议的完整完成证明从使用新增 Runtime 记录能力的 generation 开始适用。

## F02/T17：覆盖前落稳、跨 runner 恢复

可变 Web 壳快照保存旧字节、元数据、原本不存在的对象、预期新字节摘要和原冷备目录。完整 capsule 通过现有生产主机锁写入 `/var/lib/agent-saas-release-recovery/web/`，按摘要不可变保存；文件与目录同步落盘后才原子写入 pending 屏障，并另行回读确认。任何可变 OSS/冷备写入必须在该屏障之后。恢复 bytes 不上传诊断 artifact。

同一 RC 后续尝试首先读取原 pending capsule，而不是把已经部分更新的 Web 重新备份成“旧版”。先核验全部 OSS 对象仅包含原旧字节或该次预期新字节，再使用原 run/attempt 恢复冷备与完整 Web 壳并验证。恢复失败保留屏障；只有恢复完成才能写 `rolled_back`。其他 RC 和兼容 Web-only 写入被未解决屏障阻止，不能越过旧事务继续覆盖。已经存在的 hash 资源不删除。

全部 Web 与冷备校验成功才提交 `committed`。提交确认消息丢失时不得自动撤销已提交事务；下一次运行读取持久结果。终态不能被改写，也不能由相同 run/attempt 重新开启旧快照。快照损坏、缺失、大小越界、符号链接或不同发布身份失败关闭，不以忽略错误继续。

该保证覆盖遵守主机写锁的发布入口；不承诺阻止管理员绕过协议直接写 OSS。恢复前发现第三种字节会拒绝覆盖。主机持久盘本身毁损、灾备恢复及旧浏览器已安装 Service Worker 的行为仍需单独云端演练。

## F16：可移交且受限的诊断材料

生产 artifact 增加完整操作回执、逐组件回滚 reader 的 present/absent/unreadable/invalid 结果、固定退役目标与计数报告、Web 日志屏障回执、恢复对象与摘要、预算和退出码。汇总包含资源/阶段/重试、组件矩阵、恢复范围与下一步动作。失败也尽力收证；缺失材料仍明确为未知，不归一为成功。诊断字段投影、文件类型和大小均受限，不包含 OSS/SSH/数据库凭据、原始 Web 恢复 bytes、用户 prompt 或业务文件。

## 隔离回归

回归直接执行实际 Node 模块与 Bash 恢复编排，覆盖 runner 本地文件丢失、持久写入确认丢失、恢复步骤失败、第三种版本拒绝、异步锁子进程 stdin、原 run/attempt 绑定、槽位/PID 复用、重启、systemd 终态回收、排空失败、缩减清单和脱敏边界。

新增 PostgreSQL 契约通过应用原有 Event/Run/Invocation 初始化器建立独立随机前缀数据，并验证合法新 owner、终态、取消送达与未知工具结果。测试只接受本地测试数据库，不执行生产查询，不静默跳过。原有 CI、迁移分类器、内容绑定审核、主机锁、操作/回滚预算及未知副作用门禁保持。

## 运维收尾

pending capsule 和未结清退役材料不得自动删除。终态 capsule、观察文件和 systemd 观察单元暂保留供追溯，需按主机证据保留策略归档与回收；本批不做自动删除。正常业务部署成功与旧工作完整结清仍是两个独立状态。真实 ACS/OSS/CDN、长期在途任务、云端主机故障和浏览器旧客户端验收不由本批 CI 替代。
