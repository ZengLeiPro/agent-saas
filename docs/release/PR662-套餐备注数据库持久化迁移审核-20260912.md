# PR662 套餐备注数据库持久化迁移审核

## 变更结论

`server/src/quota/providerQuotaSnapshotStore.ts` 在既有套餐到期编辑审计表上追加两个可向后兼容的字段：`note`（可空文本）与 `edit_kind`（非空，默认 `expiry`）。既有到期记录通过默认值保持原语义；备注和到期时间继续共用同一张追加式审计表，并用 `edit_kind` 分开读取和写入，避免任一类清除操作覆盖另一类状态。

初始化同时包含 `ADD COLUMN IF NOT EXISTS` 兼容路径，可在已有生产表上重复执行。没有删除列、改写旧数据、回填或 contract 操作。

## 验证

- `server/src/quota/providerPlanExpiry.pg.test.ts` 在真实 PostgreSQL 上重复初始化表结构，并验证备注写入、跨实例回读、清除和到期记录隔离。
- `server/src/quota/providerQuotaSnapshotStore.test.ts` 验证初始化兼容 DDL 以及到期/备注两种追加写入的 SQL 参数。
- 备注的管理接口复用套餐到期接口的管理员认证、用户身份和 fresh overview 回读链路。

本记录仅审核 expand 变更；数据库后置检查由发布迁移后置条件绑定并在 Staging/Production 发布时执行。
