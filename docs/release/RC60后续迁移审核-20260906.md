## 独立运行期发现

真实设备注册后，claimDelivery 的 updated_at 等值条件会因 PostgreSQL 微秒精度与 JavaScript Date 毫秒精度不一致而返回 null。该项是 APNs 投递缺陷，不是迁移结构不兼容；本审核不声明 APNs 真实投递已验收。
