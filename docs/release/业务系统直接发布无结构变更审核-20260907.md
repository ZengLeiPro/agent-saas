# 业务系统直接发布无结构变更审核

PR #556 取消版本双人复核，并合并业务系统与组织接入页面。

## 审核范围

`server/src/kyapp/systems/store.ts` 属于启动建表根模块，因此发布分类器要求精确审核记录。对照 PR 基线，构造函数、`init()` 以及所引用的治理迁移代码均未修改；没有新增 DDL、建表、索引、字段或启动回填。

改动仅发生在运行期：移除 reviewVersion 的不同登记人限制、移除 publishVersion 的 pending 拒绝条件，并在管理员显式发布时将该条版本已有 review_status 从 pending 写为 not_required。approved 历史记录及 reviewReasons 保留。没有批量更新，没有新枚举值；CAS、事务、退役状态校验和审计仍生效。

分类：`no-schema-change`。审核记录绑定基线和目标文件 SHA-256，任一内容变动须重新审核；不修改分类器、Workflow 或数据库迁移门禁。

## 验证

- 真实本地 PostgreSQL：历史 pending 版本由原登记人发布成功；review_status 变为 not_required，reviewedBy 保持空，reviewReasons 保留；过期 CAS 拒绝。
- HTTP 与 PostgreSQL 管理链路：管理员直接发布、组织安装、凭据一次领取、成员授权与停用回读通过。
- HTTP 契约：同 digest 幂等、管理员直接发布、普通成员与组织管理员无发布权限、工具注册失败和退役版本仍拒绝。

回滚代码不需要结构回滚；已经发布的版本继续保持 published。未发布的历史 pending 版本在旧代码下恢复原复核要求。
