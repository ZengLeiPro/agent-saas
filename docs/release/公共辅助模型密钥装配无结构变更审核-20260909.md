# 公共辅助模型密钥装配无结构变更审核

审核日期：2026-09-09。审核范围为公共辅助模型 SecretVault 密钥装配修复，以及它对既有启动期数据库迁移调用链的影响。

## 结论

本次变更不引入数据库结构或数据迁移。`server/src/app/runtime.ts` 仅将模型配置的 SecretVault 解析提前到标题生成、智能分组、门禁模型链装配之前，并让图片理解读取当前已解析的运行时模型快照；没有新增、修改或删除 SQL、DDL、回填、迁移版本及数据库初始化调用。

既有工具提示语存储、治理迁移和其他启动期数据库初始化的调用位置与语义保持不变。因此历史迁移审核中的 `runtime.ts` 仍沿用原分类，数据库发布契约不变。

## 回归证据

- `server/src/app/runtimeModelAssembly.test.ts`：验证仅持久化 `apiKeyRef` 时，主模型、标题生成/智能分组、门禁和图片理解均从同一已解析快照取得密钥；缺失引用时启动失败。
- `server/src/app/modelResolvers.test.ts`：验证模型热更新后，惰性公共辅助模型链读取最新已解析快照。
- 相关 5 个测试文件共 13 个用例通过。
- Server 类型检查与生产构建通过。
- 行数及环境变量约束门禁通过。
- Linux CI 的 server、web、shared、PostgreSQL 契约和真实发布包检查均通过。

本审核只确认无数据库迁移影响，不替代部署后的配置身份、SecretVault 可读性和业务功能验收。
