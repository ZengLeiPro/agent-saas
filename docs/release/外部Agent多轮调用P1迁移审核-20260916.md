# 外部 Agent 多轮调用 P1 迁移审核

- 日期：2026-09-16
- 阶段：P1 多轮外部 Agent API
- 结论：`expand`，可先于业务流量发布，不修改或回填任何既有表。

## 结构变更

`PgExternalConversationStore.init()` 在 PostgreSQL advisory lock 内幂等创建两张新表：

- `<prefix>_external_conversations`：保存 API Client、租户、专用账号、外部会话 ID、内部 session 绑定和请求幂等信息。
- `<prefix>_external_executions`：保存一次外部消息提交、内部 run/session 绑定、提交状态和公开错误信息。

两表只引用 P0 新增的 `<prefix>_external_api_clients`，没有修改、删除、重命名既有列或约束，也没有启动回填。唯一约束固定外部会话、幂等请求、内部 session、run 和 canonical client message 的一对一关系。

## 运行期写入

- 创建 conversation/execution 使用 `INSERT ... ON CONFLICT DO NOTHING`，冲突后按 API Client 和幂等键读取原记录。
- 接受运行时提交后，在单个事务内绑定 conversation session 与 execution run；不一致绑定整体回滚。
- 拒绝仅更新本批新增 execution 行，不触碰 P0 身份表或其他运行时表。
- API Key、数据库密码和完整连接串均不进入这两张表。

## 回滚边界

应用代码可以回滚而保留两张新增表；旧版本不会读取或写入它们。删除表属于后续独立 contract 迁移，不包含在本阶段。
