## 结构结论

本次迁移分类为 `expand`。新增 `${tablePrefix}_external_api_clients` 表，用于保存外部调用方与专用个人账号的绑定关系、API Key 哈希、作用域、允许的只读连接、有效期、撤销状态及审计时间。新增两个普通非唯一索引，分别支持租户管理列表和专用账号反查。

迁移只执行 `CREATE TABLE IF NOT EXISTS` 和 `CREATE INDEX IF NOT EXISTS`，不删除或重命名已有表、列、索引，不回填或改写历史数据。旧版本不读取该表；回退旧版本时可以保留新表，不影响旧服务运行。表初始化在 PostgreSQL advisory lock 内执行，并且可重复执行。

运行时 SQL 只对新表执行参数化的 `SELECT`、`INSERT` 和 `UPDATE`。表名来自配置表前缀经标识符规整后的固定组合，不接受请求参数。明文 API Key 不入库，只保存 SHA-256 摘要与展示前缀。

## 后置条件

发布后使用 `runtimeEventStore` 的实际 `$tablePrefix` 只读回查：

- 表存在且 17 个列的类型、可空性与运行时读写契约一致；
- `client_id` 主键、`key_hash` 唯一约束和 `status` 状态约束有效；
- 租户时间索引和专用账号索引存在且 `indisvalid=true`、`indisready=true`。

后置条件已绑定在 `config/release-migration-postconditions.json`；源码、测试和本文摘要绑定在 `config/release-migration-reviews.json`。任一文件字节变化都需要重新审核。
