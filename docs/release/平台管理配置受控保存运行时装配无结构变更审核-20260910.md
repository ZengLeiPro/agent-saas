# 平台管理配置受控保存运行时装配无结构变更审核

## 结论

本次 `server/src/app/runtime.ts` 变更分类为 `no-schema-change`。改动只把生图配置、租户远程 Hand 环境池及 Codex 凭据版本协调器接入既有共享配置刷新和受控发布事务，不新增、修改或删除 SQL、DDL、迁移版本、启动建表、数据回填或数据删除。

## 装配边界

- 生图运行态更新仍写入既有内存配置对象，并在候选校验后由共享刷新事务提交或回滚。
- 租户远程 Hand 使用内存快照向后续注册、预热和沙箱生命周期提供一致视图；凭据仍由既有 SecretVault 按引用解析。
- Codex 正常 token 刷新通过既有生产配置发布协调器更新签名的凭据版本摘要，不引入持久化数据结构。
- 既有 PostgreSQL store、治理迁移、工具提示语动态存储及其初始化调用位置和语义不变。

- `server/src/app/tenantRemoteHandsRuntimeUpdate.test.ts` 覆盖环境池热替换和凭据解析。
- `server/src/__tests__/codexCredentialConcurrency.test.ts` 覆盖 token 刷新与签名凭据版本摘要协调。
- 正式 Server 类型检查、构建、迁移计划与历史迁移审核必须在最终提交继续通过。
