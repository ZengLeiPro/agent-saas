# 生产模型在线发布运行时装配审核

## 本次源码增量

本次相对 `9bfd1a56ec561f63570a8e58f7cd4f0e13f5c262` 的 `server/src/app/runtime.ts` 修改仅涉及配置运行态装配：

- 向模型配置刷新器注入记忆向量索引的准备、提交、回滚和旧监听器退役逻辑。
- 执行侧配置刷新增加签名配置事务准入判断，未完成的配置事务不允许新任务使用候选版本。
- 运行时就绪后装配生产模型配置发布器、两个进程的应用回执以及中断恢复轮询。
- 模型管理接口使用独立受控发布服务；其他配置管理接口保持现有生产限制。
- 停机时先停止配置发布观察器，再关闭已有记忆索引服务。

没有新增或修改 SQL、DDL、数据库迁移、启动建表、数据回填、数据删除或业务 store 的初始化顺序。本次增量分类为 `no-schema-change`。文件系统新增签名配置日志和快照属于配置治理持久化，不是数据库迁移；其初始化只发生在受控部署命令中，不在 Runtime 启动或管理 GET 中发生。

## 历史审核边界

历史基线中已经包含的工具提示语存储、治理表等数据库变更仍按原来的 `expand` 或其他审核分类处理。本次仅在对应文件的目标源码摘要更新后追加本说明，不把历史结构变更降级成 `no-schema-change`，不删除原理由或证据。

配套测试包括生产 HTTP 保存、凭据轮换、API/Worker 精确版本回执、跨进程重启、事务失败恢复、发布互斥和签名配置身份读取。测试通过情况以 PR #593 对应提交的检查记录为准；本审核文件本身不声明尚未执行的测试通过，也不授权合并、部署或修改生产资源。
