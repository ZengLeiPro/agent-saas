# 2026-09-05 移动端 P3 契约扩展迁移审核

PR：`task/mobile-p3-employee-surfaces-20260905`（移动 App 与 Web 对齐 P3 + 三项服务端契约扩展）。审核对象为发布迁移分类器闭包内本 PR 改动的两个文件；其余 `server/src/runtime/*` 改动不在启动迁移闭包内，由常规测试门禁覆盖。

## 逐文件结论

| 文件                                   | 分类             | 审核依据                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `server/src/data/feedback/store.ts`    | expand           | 消息反馈新增评分：`init` 追加一条 `ALTER TABLE <feedbackTable> ADD COLUMN IF NOT EXISTS verdict TEXT DEFAULT 'down'`（可空 + 静态默认值，不 DROP、不回填、不加 NOT NULL）；`INSERT` 增加 `verdict` 列与第 10 个参数；读取路径回传 `rating`（`verdict` 作为历史同义字段保留）。旧版服务端不写该列时由默认值兜底，新旧两版可同时连同一套库（N/N+1）；表名为构造期常量插值，与同文件既有 `CREATE TABLE`/`CREATE INDEX` 写法一致。 |
| `server/src/data/transcripts/parse.ts` | no-schema-change | 仅类型层改动：`TranscriptBlockKind`/`TranscriptSubagentActivity`/`TranscriptBlock` 类型抽到 `parseBlockTypes.ts` 并以 `export type ... from` 转发（行数棘轮要求）；`failureKind` 由字面量 `'policy_rejection'` 放宽为 `RuntimeFailureKind`（新增 `quota_exhausted`）。无 SQL、建表或回填变化，运行期解析逻辑逐字不变。                                                                                                         |
