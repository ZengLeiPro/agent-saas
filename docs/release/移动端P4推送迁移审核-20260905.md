# 2026-09-05 移动端 P4 系统推送（APNs）迁移审核

PR：`task/mobile-p4-push-20260905`（移动 App 与 Web 对齐 P4：iOS 系统推送）。审核对象为发布迁移分类器闭包内本 PR 改动的三个文件；其余服务端改动（推送扇出接口、路由收口、装配层）不在启动迁移闭包内，由常规测试门禁覆盖。

## 逐文件结论

| 文件                                 | 分类             | 审核依据                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------ | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `server/src/apns/store.ts`           | expand           | 新建文件，文件顶部独立 `// release-migration: expand` 注释。`init` 只执行 `CREATE TABLE IF NOT EXISTS <prefix>_apns_devices`（设备令牌，`token_hash UNIQUE`，`environment` CHECK）、`CREATE TABLE IF NOT EXISTS <prefix>_apns_deliveries`（投递幂等记录，复合主键 `(device_id, event_key)`，刻意不建外键、无 `ON DELETE CASCADE`）与两条 `CREATE INDEX IF NOT EXISTS`；advisory lock 串行 init，重复启动幂等。不改任何既有表。`DELETE`/`UPDATE`/`INSERT … ON CONFLICT` 均为运行期设备注册、注销与投递 claim 方法，不在启动路径。旧版服务端不认识这两张表也不受影响（N/N+1 双版本可共存）。 |
| `server/src/app/config.ts`           | no-schema-change | 仅把 `webPushConfigSchema`（Zod 定义，24 行）原样抽到 `pushConfigSchema.ts` 并改为 import；新增 `apns: apnsConfigSchema.optional()` 配置域与 `ApnsConfig` 类型导出。无 SQL、建表或回填；配置解析行为对既有 `webPush` 字段逐字不变（行数棘轮要求抽块）。                                                                                                                                                                                                                                                                                                                                    |
| `server/src/app/pushConfigSchema.ts` | no-schema-change | 新建文件：`webPushConfigSchema`（从 config.ts 原样迁入）与 `apnsConfigSchema`（teamId/keyId/privateKey/bundleId/environment 的 Zod 校验）。纯配置定义，无数据库执行。                                                                                                                                                                                                                                                                                                                                                                                                                      |
