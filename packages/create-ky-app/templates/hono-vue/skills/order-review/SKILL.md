# 订单巡检

## 什么时候用这个技能

用户想让 AI 同事把订单**看一遍并给结论**，而不是简单查一条数据时使用。
单纯的「查订单 SO-123」直接用工具 `app____SYSTEM_IDENT____order_search` 就够了，不必走本技能。

## 取数方式

**只能通过 `app__` 前缀的工具取数**：

- `app____SYSTEM_IDENT____order_search`：按客户名或订单号查询，最多 10 条，可翻页。

不得直连数据库，不得自己发 HTTP 请求，不得在技能里写任何凭据。
需要更多数据时，用不同关键词或翻页多调用几次工具。

## 步骤

1. 明确范围：用户说的是哪个客户、哪一批订单？范围不清就先问一句。
2. 用 `order_search` 取数；结果超过一页时按 `nextCursor` 继续取，最多取 5 页。
3. 逐条看三件事：
   - 金额是否明显偏离该客户的常见区间；
   - 状态是否长期停留在草稿；
   - 是否存在同客户、同金额的疑似重复下单。
4. 输出结论：先给一句话总览，再列出需要跟进的订单（订单号 + 原因 + 建议动作），最多 10 条。

## 输出要求

- 中文，直接说人话；不要复述工具返回的原始字段名。
- 每条建议都要能落地（找谁、做什么），不要写「建议关注」这种空话。
- 拿不到数据时如实说明「暂时取不到订单数据」，不要编造，也不要解释技术原因。
