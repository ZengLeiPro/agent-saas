当用户需要把本地音频/视频文件或公开的 http/https 音频直链转成文字时，使用 AudioTranscribe。输入只允许当前工作区内的相对路径或 http/https URL；本地路径会校验真实路径与 symlink，禁止访问工作区外文件。音频数据会提交给阿里云百炼 DashScope：本地文件会先临时上传到平台配置的阿里云 OSS，任务结束后清理临时对象；直链会直接提交给百炼。处理敏感录音、客户录音或个人隐私内容前，先向用户说明外部处理事实并取得确认。可用 `speaker` 开启说话人分离，用 `timestamps` 在每句前添加 `[HH:MM:SS]`，结果按句换行。调用成功后转写文本会自动写入 `assets/YYYYMMDD/<原名>-转写-<uuid8>.txt`，且不会覆盖已有文件；请在最终回复中原样使用并明确告知用户工具返回的 `outputPath`。在收到工具成功结果前不得声称转写已完成，也不得编造输出路径。余额不足时调用会在提交外部服务前拒绝；转写或落盘失败不扣费。
