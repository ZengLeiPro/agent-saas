管理当前用户的定时任务与任务看板。target 默认 cron：支持 list/create/update/delete/run。target=taskboard 时，普通会话按当前登录用户、租户、看板角色及服务端 allowedActions 访问；支持 board/task/comment/execution/integration 资源 action、分页查询、CAS 写入、任务派发和人工集成批次。由任务看板派发的 Execution 会按 Run/Session 反查当前任务和职责，可读取当前任务的全量或增量上下文、写入 Agent 进展并携带 context receipt 提交结构化 resolution；不能伪装成普通管理会话、扩大仓库权限或绕过工作流。work Execution 可登记 Provider PR，review Execution 记录不可变 subject，merge Execution 只能通过受控 integration source 操作检查或合并已复核 PR；可写仓库凭据不进入 review/merge Runtime。work、review、merge 的允许结果由同一个 workflow contract 决定；服务端校验 task version、change sequence、policy revision、contract digest 和 reviewed subject。组织看板角色为 viewer/editor/maintainer/owner：viewer 只读，editor 及以上可评论和触发，人工集成批次需 maintainer/owner。cron 与 taskboard 只读 action 无需审批；可逆看板写操作按 workspace_write 审批，派发、评论删除、integration 授权与 cron 写操作保持高风险审批。
