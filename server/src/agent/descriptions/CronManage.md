管理当前用户的定时任务与任务看板。target 默认 cron：支持 list/create/update/delete/run。target=taskboard 时，普通会话按当前登录用户、租户及看板可见性访问，不需要 taskboard-* runId；支持分页的 board.list/board.search/board.get、task.list/task.search/task.get、comment.list、execution.list，以及 board.create/update/archive/restore、task.create/update/move/archive/restore/dispatch、comment.create/update/delete。资源写操作使用 expectedVersion 做 CAS；task.create 可传 dispatch=true 立即派发 work Agent；同一任务的活跃 Execution 仍由服务端唯一约束阻止重复派发。由看板派发的 taskboard-* Execution 继续只允许旧 list/create/update/move/execute action，并按 runId 反查当前 Execution：只能读取当前任务、回写自己的 branch、创建 todo 后续任务，独立 review Execution 才能 move done/todo，不能伪装成普通管理会话。所有对象均由服务端反查 tenant/owner/visibility 权限；工具调用审计记录操作者、来源 Session、参数、结果与时间。cron 与 taskboard 只读 action 无需审批；可逆 taskboard 写操作按 workspace_write 审批，派发、评论删除与 cron 写操作保持高风险审批。
