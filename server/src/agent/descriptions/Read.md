读取当前工作区内的 UTF-8 文本文件或图片。支持 PNG、JPEG、GIF、WebP；图片会直接作为视觉输入提供给支持看图的模型，不需要调用 browser skill，传入的 `offset`/`limit` 会被忽略。文本小文件原样完整返回；大于 131072 字节的文件返回前 131072 字节并附续读提示。读大文本文件时可传 `offset`（1-based 行号）和 `limit`（最多 2000 行）读取指定行区间。路径精确打开失败时会尝试 Unicode 空格、NFC/NFD、弯引号和可选 `@` 前缀自愈；单行超过输出预算时返回可直接执行的 `sed | head` 建议。
