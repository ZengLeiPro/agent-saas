# Audio Transcribe - 音频/视频转文字

使用平台 `AudioTranscribe` 工具将录音或视频转为文字。本 skill 只负责语音识别转写；如需整理、总结或翻译，应先完成转录，再单独处理文本。

处理敏感录音、客户录音或含个人隐私的内容前，必须说明内容将提交给平台配置的转录服务，并取得用户确认。

如果用户提供的是 B 站、抖音、YouTube 等视频平台页面链接，而不是可直接访问的音视频文件 URL，应先用 `media-download` 下载视频或提取音频，再把本地文件交给本 skill。

## 调用方式

调用平台 `AudioTranscribe` 工具，并传入：

- `input`：必填，本地音频/视频文件路径，或可直接访问的 HTTP(S) 音视频 URL。
- `speaker`：是否启用说话人分离。多人会议、访谈或对话场景建议设为 `true`；单人录音通常设为 `false`。
- `timestamps`：是否在结果中保留时间戳；用户只要纯文本时设为 `false`。

识别模型及服务凭据由平台管理员统一配置。调用时不得让用户选择、指定或切换模型，也不得自行覆盖平台配置。

## 结果交付

- 成功后，以工具返回的 `outputPath` 作为转录文件交付给用户。
- 可引用工具返回的 `text` 做简短预览，或在用户要求时用于后续整理和总结；不得篡改原始转录文件并冒充识别原文。
- 如工具报告余额不足、平台未配置转录服务或其他错误，应如实说明具体状态，不得声称转录成功，也不得私自改用其他服务。

## 禁止事项

- 禁止执行 `scripts/transcribe.py` 或任何 Python/Shell 转录命令。
- 禁止读取、检查或要求用户提供与转录服务有关的环境变量、API Key 或云存储凭据。
- 禁止通过 Shell、HTTP 请求或第三方 SDK 绕过 `AudioTranscribe` 工具。
