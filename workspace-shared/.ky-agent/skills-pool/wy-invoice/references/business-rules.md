# 唯恩施耐德发票业务规则

## 数据来源

- T100 待办接口：返回可联调的对账单、发票金额、发票日期和施耐德登录信息。
- T100 Excel 接口：按 `dh=<对账单号>` 下载 `.xlsx/.xls`。
- 客户 2026-07-27 明确：第一个接口返回的对账单号均可联调；返回空数据代表业务部门可能已处理，需要在群里请求补数据。

## 非寄售

1. Excel“发票备注栏”与 T100 发票备注完全一致。
2. 从匹配行计算收货日期起止区间。
3. 逐页按“订单号+行号”精确选择并放入发票篮。
4. Excel 重复键、网页重复键或网页缺行均立即停止。
5. 货款总额必须等于 T100 原币税前。
6. 填写发票号、开票日期、含税金额、税额，检查结果必须为 0。
7. 最终确认成功后下载当日报表并幂等合并。

## 寄售

1. 从发票备注解析凭证日期起止区间。
2. 查询结果必须恰好一行。
3. 汇总金额必须等于 T100 原币税前。
4. 后续发票字段、检查结果和最终确认规则与非寄售相同。

## 最终确认门禁

- `task_reference`、`commit_reference`、`confirm_submit` 三个值必须完全一致。
- 最终确认页逐标签核对：
  - 发票号码；
  - 开票日期；
  - 发票总额（含税）；
  - 增值税额。
- 点击后必须观察到明确成功文本、弹窗、结果窗口或离开确认页；20 秒内没有成功证据即判失败。
- 当前阶段客户允许确认施耐德网页，但尚未提供 T100 回写协议。结果必须写成“施耐德已确认，T100 未回写”，不能写“ERP 全闭环”。

## 证据与脱敏

- 每个运行目录包含日志、截图和 DOM 快照。
- 客户系统账号、密码、token 不写入日志和最终回复。
- 金额不一致时保存截图并停止，不允许用四舍五入或模糊容差绕过。
